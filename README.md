# YogaRam

Android-клиент YogaRam Messenger. Это изменённая версия [Telegram для Android](https://github.com/DrKLO/Telegram) (снимок `f32ffeec`, версия 13.0.2), лицензия GNU GPL v2. Текст лицензии — в `LICENSE`, уведомления об авторских правах Николая Кудашова сохранены в исходниках. Оригинальный README upstream — в `TELEGRAM_README.md`.

Клиент подключается к своему серверу Opengram (MTProto), а не к серверам Telegram.

- `applicationId`: `ru.myfbt.yogaram`
- имя приложения: YogaRam
- DC1 (ThisDcId): `46.8.46.56:20443`, имя `nandagram.myfbt.ru`
- DC2 (MediaDcId): `46.8.46.56:20543`
- код входа на тестовом сервере: `22222`

Сборка и список правок: [CLIENT_BUILD.md](CLIENT_BUILD.md).
